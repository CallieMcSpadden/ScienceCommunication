# Science Communication

Interactive visual explainers for science concepts. Each project is a single self-contained HTML page that runs in any modern browser with no build step.

## Projects

| Project | Description |
| --- | --- |
| [Hydrogen Probability Cloud](hydrogen-atom/) | A rotatable 3D dot cloud of the hydrogen atom, sampled from its quantum wavefunctions. Shows electron orbitals from 1s to 4f, plus a zoomed view of the nucleus for protium (¹H) and deuterium (²H). |

## Viewing a project

Open the project's `index.html` in a browser. To publish the pages online, turn on GitHub Pages for this repository (Settings → Pages → deploy from the `main` branch). Each project will then be available at `https://<username>.github.io/<repo>/<project>/`.

## Adding a project

Create a new folder with an `index.html` inside it, then add a row to the table above.
